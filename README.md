# Fred Myers and the Moonpetal Marsh

A responsive, installable 3D-styled browser game about a brave frog crossing a dangerous enchanted pond.

## Play

- Click or tap to aim. Click nearby bugs to eat them.
- Use Arrow keys or WASD to steer.
- Hold Space or Shift for a limited energy boost.
- Press Q to dive and E to surface, or use the on-screen buttons.
- Hide in shoreline holes, dodge herons and snakes above water, and evade fish below.

## Run locally

Install dependencies and run the development script. The game is a Progressive Web App and can be installed from a supporting desktop or mobile browser.
