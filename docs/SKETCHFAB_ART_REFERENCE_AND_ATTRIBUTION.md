# Sketchfab art reference and attribution

Updated: 2026-08-24

## Use boundary

Fred's game characters remain original Fred-owned, phone-safe Godot vector
drawings. The following Sketchfab models were used only as visual anatomy,
silhouette, scale, feather, and material references for this local art pass.
No Sketchfab model, texture, thumbnail, animation, source archive, or remote
viewer is bundled in the project. The game has no Sketchfab runtime or network
dependency.

This boundary is deliberate. Sketchfab's official download flow requires an
authenticated account and Creative Commons attribution must follow any model
that is actually used. This pass did not authenticate, download, convert, or
redistribute any model file.

## Runtime integrity

- Character drawing remains deterministic and presentation-only.
- Collision shapes, predator hit rules, lives, objectives, progression,
  Golden Egg state, touch controls, Game Center integration, Core 0.5.1, and
  `fred_save` v1 remain authoritative outside the art layer.
- The source URLs are documentation only and are never opened by the game.
- Any future direct model import requires a separate authenticated download,
  license/attribution audit, phone performance review, and owner acceptance.
