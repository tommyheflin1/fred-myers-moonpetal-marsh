# Fred Myers support page draft

## Fred Myers and the Moonpetal Marsh support

Fred is a touch-first landscape adventure for iPhone and iPad. No separate
account is required.

### Quick help

- Touch or drag on the marsh to steer Fred.
- Use MUNCH for nearby bugs and tenth-level fairies.
- Use LEAP to clear surface danger, BOOST for short bursts and DIVE/SURFACE to
  move between water layers.
- PAUSE keeps the current run safe. EXIT returns to the title and starts a
  fresh run next time while preserving earned cosmetic coins.
- If Game Center is unavailable, local play, saves and Marsh Leaders continue
  to work offline.

### Save recovery

Fred writes a local atomic save and keeps a recovery copy. If the newest save
is incomplete, the app uses the last valid recovery point and explains the
result on screen. Do not uninstall the app when seeking save help because
uninstalling can remove device-local progress.
